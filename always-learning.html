// Software-Defined Radio Just started

I recently bought a Nooelec NESDR Smart v5, an RTL-SDR in an aluminum enclosure. It's a USB receiver built around the RTL2832U, a chip originally made for digital TV dongles. With the right software it becomes a wide-band, receive-only software-defined radio: the hardware digitizes a slice of the radio spectrum, and the decoding happens on the computer.

My plan is to put together a dedicated Linux box for it, so I can leave it running and learn the software side properly.

  • RadioNooelec NESDR Smart v5
  • ChipsetRTL2832U + R820T2 tuner
  • Range100 kHz – 1.75 GHz
  • Clock0.5 PPM TCXO
  • Antennas3 included, SMA input
  • ComputerLinux box (planned)
  • StatusJust getting started
